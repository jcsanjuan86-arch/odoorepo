# Prime Auto Boutique Odoo Repository

This repository is connected to Odoo.sh.

Current setup:
- Odoo Online/Studio workflows are kept in the live Odoo database.
- This Git repository is prepared for future Odoo.sh custom modules only.
- No custom Python automation code is required for the current manual workflow.

Recommended branch use:
- `main` - production branch
- `staging` - testing branch
- `dev` - development branch
